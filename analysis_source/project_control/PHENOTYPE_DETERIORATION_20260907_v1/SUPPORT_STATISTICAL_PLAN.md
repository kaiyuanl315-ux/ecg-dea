# Recorded organ support statistical specification

2026-09-07. Specified after descriptive source QA and before any organ-support association estimates. This remains a post-review exploratory extension. Read with SUPPORT_ANALYSIS_PLAN.md; ICU transfer is the principal care-escalation analysis.

The four principal tests are the ECG-only M2 associations with ICU-recorded invasive ventilation and five-drug vasopressor support within 24 and 72 hours. Apply Benjamini-Hochberg correction within these four tests, separately from the six phenotype and two ICU-transfer families. Preserve the original saved ten-run ECG-only score and its training-only logit standardization. M1 adjusts for age and sex; M2 adds the same four processed initial vital signs and training-defined splines as the phenotype/ICU analysis. Fit logistic GLMs with patient-cluster robust confidence intervals. Use the frozen parent processed clinical values; no raw missingness reconstruction, new imputation, or heart-rate adjustment.

M1 and Fusion-DL M2 estimates are secondary descriptive results. Prespecified sensitivity analyses use the first chronological encounter in the parent test partition before endpoint filtering, the saved single-run ECG-only score, and each endpoint's 60-minute landmark. The original 24/72-hour horizon remains anchored to ECG. Definition sensitivities use the unfiltered direct raw invasive-state definition, five-drug support excluding dopamine, and five-drug support excluding Bolus status segments. These do not replace the principal definitions based on results; their p values are nominal.

Report endpoint-specific eligible n and events and adjusted model n after the existing demographic mask. Fewer than 30 events, separation, or nonconvergence precludes adjusted inference and requires descriptive reporting. Missing observation is not an event-negative record.

For each of the four principal endpoints, report observed proportions in the unchanged three Fusion-DL mortality-score strata with 2,000 patient-cluster bootstrap percentile intervals. Seed is 20261001 plus the endpoint index (imv24, imv72, pressor24, pressor72). Do not develop a new support prediction model, select new thresholds, interpret mortality probabilities as calibrated support risk, or add support ROC comparisons. Repeat the pipeline from frozen inputs into a separate output directory and compare results before manuscript delivery.
