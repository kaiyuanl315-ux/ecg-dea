# JAHA拒稿后补分析：固定方案 v1

日期：2026-09-06。性质：作者授权的、审稿后新增分析，不追溯宣称为原研究预先注册。此方案先于本次校准拟合、对照模型选择和新增测试评估写入；已有文章和历史测试结果此前已被查看。

## 已确认的研究边界

- 作者确认：完全回顾性、离线分析，模型输出没有参与实际分诊、检查、住院或治疗。
- 作者同意：拟研究用途为高风险提醒、辅助医生重新评估；不用于减少检查、提前出院或替代医生判断。当前结果不证明改善结局或临床使用安全性。
- 研究对象为接受早期ECG检查的急诊患者，不是所有急诊患者。
- 不改变现有队列名单、结局标签、融合模型或原稿。不追查暂缓的ECG预测缺失原因和IG样本对应问题。

## 第一批：校准与阈值诊断

1. 内部使用现有10次运行的保存平均评分：训练/验证/测试分别为126849/17889/35948条。以文件标识核对结局、患者、fold和一一对应关系，患者不得跨划分。
2. 仅在内部验证集拟合一个预先指定的无权重、无惩罚logistic再校准器：`logit(p_cal)=a+b*logit(p_raw)`，计算logit时截断至[1e-8,1-1e-8]。不比较多种校准法后按测试结果选优。b必须为正。原验证集历史上也用于基础模型选择，不称其为独立于基础模型开发的全新校准队列；拟合表现仅标为apparent。
3. 从验证集按已存在规则重建阈值：低阈值为敏感度至少0.90时特异度最大；高阈值为敏感度至少0.50时PPV最大。使用精确浮点阈值、`score >= threshold`为警报。核对原稿四舍五入阈值0.45630312和0.61627972；不根据测试集重新选阈值。
4. 保存校准系数、阈值、输入哈希后才做本次测试评估。将两个原始阈值经同一校准器映射到新概率尺度；验证校准前后警报逐条完全一致。不在校准后继续用原始数值阈值。
5. 外部保留文章对应文件的`proba_mean_2`，并预先指定`proba_mean_1`为评分来源敏感性分析。两者一并报告，不能择优。此文件有历史评分回填/来源混合问题，不能把这次统计重算标为全流程无偏外部验证或新推理结果；不改其标签或成员。
6. 测试集上的校准截距、斜率拟合仅为评估失校准的诊断回归，不回写校准器，不用于更新概率或阈值。禁止把外部诊断回归当作新的部署校准器。
7. 报告Brier、队列患病率常数的Brier参照、Brier skill、O/E、平均预测与观测风险、log loss、联合诊断截距/斜率、固定斜率1的calibration-in-the-large。附AUROC、AP及梯形AUPRC（明确算法不同）。校准图使用内部验证集固定十分位分箱；分箱点是描述性观测率，不假装为拟合置信带。
8. 每个阈值报告TP/FP/TN/FN、敏感度、特异度、FNR、FPR、PPV、NPV、误报警报占比、警报比例、每1000次就诊的警报/误报/检出死亡/漏检死亡、每100个警报对应死亡和每检出一例死亡需要的警报数。计数为实际就诊层面，不称被检出死亡为可预防死亡。
9. 患者聚类bootstrap 2000次、固定种子20260906，给Brier、O/E和阈值比率等95%百分位区间；对诊断校准参数使用患者聚类稳健标准误。区间以当前冻结模型/校准器/阈值为条件，不包含重新训练与校准拟合的不确定性。每次bootstrap整位患者及其所有就诊共同重抽样。

## 第二批：补强对照（第一批完成后运行）

- 在同样训练/验证/测试患者划分上，重新拟合六变量logistic基线，以及六变量XGBoost、六变量加常规ECG参数的XGBoost。目标均为实际死亡标签，绝非拟合融合分数的替代解释模型。
- 六变量为temperature_c、resprate、o2sat、sbp、age、gender_clean；常规ECG为PR、QRS、QT间期及QRS电轴，心率仅在两中心来源明确对应时加入。缺失指标固定添加，每个训练折仅用自己的中位数填补。新对照不引入出院信息、诊断、随访或结局衍生字段。
- XGBoost预定义4配置：max_depth为2/3、n_estimators为200/500；learning_rate=.05，min_child_weight=10，reg_lambda=10，subsample=.8，colsample_bytree=1，scale_pos_weight=1，tree_method=hist。训练集内3折StratifiedGroupKFold（患者分组）按平均AP选型；平局优先较浅/较少树。验证集不参与调参，仅用于校准与阈值；外部和内部测试不参与任何选择。
- 最佳配置在完整训练集拟合，校准及阈值按第一批同样规则在验证集确定，冻结后在两测试队列评估；所有模型都报告，不根据测试成绩删模型或扩参数网格。比较范围是这些可用变量，不称其胜过全面临床评估。
- 第二批为审稿后新增模型比较，原融合模型不重训。实际可运行状态、任何不可映射字段及偏离本方案都要记录。
