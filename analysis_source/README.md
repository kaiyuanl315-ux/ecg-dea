# Scientific source snapshots

These are selected implementations behind the manuscript's additional analyses. The original hierarchy has been retained. Read `../REPRODUCIBILITY.md` before execution: historical private inputs, manifests and per-record QC decisions are required, and personal path prefixes have been replaced with placeholders.

The scripts have not been converted into a standalone public pipeline. They are distributed as reviewable source snapshots, with their specific limitations stated explicitly. The historic subfolder name `tmp` indicates the original execution location; it contains source code only in this supplement.

Plans are historical records. If an early plan describes an initial numerical tolerance or an exploratory option, it does not override the final manuscript methods or the final scientific implementation. No manuscript, journal correspondence, credentials, raw inputs or private analysis output is included here.
